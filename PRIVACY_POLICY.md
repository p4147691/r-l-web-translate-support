# Privacy Policy — R+L Web Translate for Google Chrome™

Last updated: 2026-10-03

R+L Web Translate translates visible text on the webpage currently viewed by the user into Korean using language features built into Google Chrome.

## Information handled by the extension

- The extension reads visible webpage text only to translate it.
- To restore a translated page, the original text is temporarily retained in memory for that tab.
- Extension settings, such as enabled state and language preferences, may be stored in Chrome Sync storage.

## Collection and sharing

- The developer does not collect webpage text, browsing history, translation results, or personally identifying information.
- The extension does not transmit webpage text or translation results to the developer or to a third-party translation server.
- The extension contains no advertising, analytics tracking, or remotely executed code.
- Translation model availability, download, and execution are managed by Google Chrome.

## Retention

- Original text retained for restoration exists only in the memory of the current tab and is removed when that page is reloaded or closed.
- Chrome manages saved extension settings according to its own storage policies. Users can remove those settings by removing the extension.

## Permissions

- Access to HTTP and HTTPS webpages is used only to translate and restore visible text on pages chosen by the user.
- `storage` is used to save extension settings.
- `tabs` is used to determine the active tab's primary language and prepare translation.

## Contact

For support or privacy questions, open an issue in this repository. Do not include personal or sensitive information in a public issue.

This policy describes the released implementation and is not legal advice.
