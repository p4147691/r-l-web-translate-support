# R+L Web Translate for Google Chrome™ — Support

This repository is the public support and policy site for **R+L Web Translate for Google Chrome™**.

The extension translates visible text on ordinary webpages into Korean with Chrome's built-in language features. Hold the right mouse button and click the left mouse button once to translate; repeat the same gesture to restore the original text.

## Support

Please use [Issues](../../issues) for bug reports and feature requests.

Do not post passwords, cookies, account numbers, full page captures containing private information, or other personal data. For a translation problem, the Chrome version, the affected language combination, a public URL when available, and the short error message are enough.

## Privacy

Read the [Privacy Policy](PRIVACY_POLICY.md).

## Project scope

This repository intentionally contains no extension source code, Chrome profiles, translation models, logs, credentials, or user data.
